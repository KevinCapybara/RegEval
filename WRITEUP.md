RegEval targets the FDA Complete Response Letter corpus challenge: identify deficiency paragraphs, classify them as CMC, clinical, nonclinical, labeling, or facility inspection, and report what the corpus shows about application deficiencies.

The project targets 3–10 distinct tasks, each with five datasets. Task 1 concerns CRL deficiency classification/distribution. Each dataset has a document workspace, a question, private reference labels, and a GPT-6 Luna evaluation rubric. Users select GPT-5 nano or GPT-6 Luna as the test agent; the judge is always a separate GPT-6 Luna call. Gold is hidden from the agent. A full task run evaluates all five datasets independently and aggregates their scores.

Before authoring accepted gold, we will freeze paragraph boundaries, deficiency inclusion/exclusion rules, mixed-category treatment, and distribution denominators using actual corpus examples. Each scenario's gold will cover positive and negative paragraphs and undergo an independent verification pass. Judge calibration will assess omissions, false positives, category errors, unsupported citations, duplicates, and incorrect aggregate counts or denominators.

The full-corpus report will distinguish paragraph prevalence, letter prevalence, and application-family prevalence. Gold-subset results will not be presented as verified full-corpus accuracy. Source coverage, sampling, multi-label overlap, and extraction limitations will be stated explicitly.

**Current status:** Five new private draft datasets contain 40 selected passages from five distinct application families. Exact source spans and structural consistency have been checked; independent semantic review and PDF verification remain pending. Both Nano and Luna received provisional 100% on Dataset 1 using Luna as judge. These single runs do not distinguish the models or establish general accuracy. Luna's judgment of its own answer flagged possible clinical/CMC ambiguity in the draft gold; the Nano judgment did not flag it. That inconsistency is an open calibration concern. Datasets 2–5 have now been evaluated with both agents. The provisional equal-weight Task 1 averages are Luna 99.00% and Nano 79.64%. Nano counted routine/deferred or expressly nonblocking items as deficiencies in Datasets 3–5. Dataset 3 exposed ambiguous CMC/nonclinical gold and a judge deduction despite describing Luna’s alternative labels as defensible. Scores are retained unchanged pending review. No full-corpus distribution is claimed.

New datasets add labeling corrections, multi-category impurity safety, explicitly non-approvability recommendations, and an unmet clinical-trial requirement.
